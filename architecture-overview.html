Mijn Thuisbar · architectuur-overzicht

Hoe de app in elkaar zit

Eén React-bestand (ThuisbarApp.jsx, ~6000 regels) is de hele app: één centrale staat bovenin, elf tab-componenten die daaruit lezen en erin schrijven, en sheets die er als overlay bovenop schuiven. Data komt uit drie bronnen: statische bestanden, de telefoon zelf (localStorage), en Supabase in de cloud.

1

De schil — hoe de app opstart

Zit als PWA "op het beginscherm", ziet er dan uit als een native app (geen Safari-balken).

index.html

Laadt fonts, manifest, en main.jsx. Zet de donkergroene achtergrondkleur vast zodat er geen witte flits is bij het opstarten.

manifest.json

display: standalone — geen browserbalken. Dit is ook waarom edge-swipe-terug van Safari niet werkt: die functie bestaat alleen mét browserchrome.

sw.js

Service worker: laat de app offline openen en verzorgt pushmeldingen ("vriend heeft ingecheckt").

main.jsx

Eén regel die telt: render(<ThuisbarApp />). Alles hieronder gebeurt binnen dat ene component.

De hub — ThuisbarApp()

Eerst een poortje op basis van de inlogstatus, dan bouwt het component alle gedeelde state en helper-functies die de tabs zo meteen krijgen doorgegeven.

Eerst: wie ben je?

regel 1564–1567
session === undefinednog aan het checken bij Supabase → leeg donkergroen scherm
passwordRecoverywachtwoord-resetlink geopend → PasswordRecoveryScreen
session === nullniet ingelogd → AuthScreen (login/registreren)
session = objectingelogd → de hoofd-app hieronder

5

Sheets — overlays die van onderen omhoog schuiven

Alle vier gebouwd via createPortal naar document.body (zodat ze altijd bovenop de onderbalk liggen), en sinds vandaag allemaal met vinger-omlaag-vegen-om-te-sluiten via de gedeelde useSheetDismiss-hook.

CategorySheet

Vanuit Voorraad: alle ingrediënten in één categorie, aan/uit vinken.

RecipeSheet

Receptdetail met ingrediënten + "voeg ontbrekende toe aan winkelmandje" — gebruikt vanuit Maken én Feestplanner.

BrowseSheet

Lijst recepten binnen "op basisdrank" / "op stijl" vanuit Maken.

FriendProfileSheet

Profiel + logboek-statistieken van een vriend, vanuit Vrienden.

6

Systemen die dwars door alle tabs heen lopen

Geluid

Geen audiobestanden — playSound() synthetiseert elk geluidje live met de Web Audio API (tick, pop, clink, chime, pour, share, levelup, unlock…).

Beeld: foto óf illustratie

RecipeCircle/GlassArt tekenen een SVG-glas als er geen foto is; is er wel een foto (recept, categorie, basisdrank), dan krijgt die dezelfde sepia-tint (RECIPE_PHOTO_FILTER) zodat het één geheel oogt.

Supabase Edge Function

notify-friends wordt aangeroepen bij elke nieuwe check-in, en stuurt de pushmelding naar vrienden.

statische data lokaal op dit toestel cloud / Supabase sheet / overlay schil / systeem

Alles in één bestand: src/ThuisbarApp.jsx. Geen router, geen aparte state-library (Redux/Zustand) — puur React state + props, plus de useStorage-hook voor localStorage en directe supabase.from(...)-calls voor de cloud-tabellen.
